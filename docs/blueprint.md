# **App Name**: Contador de Quesitos

## Core Features:

- Autenticación de Usuario: Permite a los usuarios elegir un nombre de usuario y un avatar para su identificación sin contraseña. Los nombres de usuario deben ser únicos. Cada 'quesito' se etiquetará con el nombre de usuario y el avatar del remitente.
- Añadir Quesito: Permite a los usuarios añadir un 'quesito' introduciendo su nombre de usuario de Instagram.
- Lista Global de Quesitos: Muestra una lista compartida de todos los 'quesitos' añadidos por todos los usuarios.
- Conteo Total de Quesitos: Muestra el número total de 'quesitos' añadidos a la lista global.

## Style Guidelines:

- Color primario: Rosa suave (#F4B4C4) para evocar una sensación amigable y acogedora, relacionada con el concepto de relaciones e interacciones.
- Color de fondo: Crema claro (#F9F6F2), una versión desaturada del primario, proporciona un telón de fondo suave y discreto.
- Color de acento: Púrpura pálido (#D0B4F4) para crear un contraste con el color primario, utilizado para elementos interactivos y resaltados.
- Fuente: 'PT Sans', una sans-serif humanista para una apariencia moderna y legible tanto en los encabezados como en el cuerpo del texto.
- Utilizar iconos sencillos y claros para las acciones del usuario, como añadir un quesito o ver la lista. Estos deben estar en línea con una estética 'linda'.
- Diseño limpio y sencillo, priorizando la facilidad de uso y la legibilidad. La lista de quesitos debe ser el centro de atención, con la información secundaria claramente etiquetada.
- Animaciones sutiles al añadir un 'quesito' o al actualizar el conteo total, proporcionando una retroalimentación positiva al usuario.
